# FX_magic-circle-generator

게임용 마법진 이펙트 이미지를 생성하고, 레이어 단위로 편집하거나 PNG/SVG 파일로 저장하기 위한 웹 도구입니다.

## 주요 기능

* 다양한 게임용 마법진 스타일 생성
* 실시간 생성 옵션 조절
* 레이어 기반 편집 기능
* 레이어 관리 기능
* 이미지 저장 기능
* 프로젝트 저장 / 불러오기
* 작업 레이아웃 선택

## 사용 방법

1. 웹 페이지를 실행합니다.

2. `생성 스타일`에서 원하는 마법진 유형을 선택합니다.

3. `Seed`, `변형 강도`, `생성 복잡도`, `장식 밀도`, `룬 밀도` 값을 조절하여 원하는 형태의 마법진을 생성합니다.

4. 필요한 경우 레이어를 선택하여 세부 속성을 수정합니다.

5. 레이어 관리 기능을 사용하여 필요한 레이어만 표시하거나, 잠금 / 복제 / 삭제 / 순서 변경을 진행합니다.

6. 완성된 마법진은 원하는 방식으로 저장합니다.

   * 전체를 한 장의 이미지로 저장하려면 `전체 합본 PNG` 또는 `전체 합본 SVG`를 사용합니다.
   * 특정 레이어만 저장하려면 `선택 레이어 PNG` 또는 `선택 레이어 SVG`를 사용합니다.
   * 모든 레이어를 개별 파일로 저장하려면 `모든 레이어 PNG` 또는 `모든 레이어 SVG`를 사용합니다.

7. 작업을 나중에 이어서 진행하려면 `프로젝트 저장`을 사용해 JSON 파일로 저장하고, 이후 `프로젝트 불러오기`로 다시 불러옵니다.
